# Project Rules: FindMe Who

## Universal Coding Rule: Ponytail
On every coding task, strictly apply the **Ponytail** engineering philosophy:
- **YAGNI:** Build only what is explicitly requested. No speculative scaffolding or unrequested abstractions.
- **Stdlib & Native First:** Leverage standard library and native features before custom code or third-party dependencies.
- **Shortest Working Diff:** Deletion over addition. Minimal, robust, and clean code that solves the root cause.
- **Zero Bloat:** Keep schemas, models, and scripts lean and strictly compliant with specifications.
